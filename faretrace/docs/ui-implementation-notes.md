# 中文界面改版说明

## 目标与风格

三个页面统一采用暖白纸感、深青绿与赭金色，配合路线插画、票据式金额摘要、留白和中文层级。用户可直接阅读适用规则、具体地点、费用计算过程和复核进度。

## 实现边界

- 页面展示层只整理保存的归因证据，不调用计价服务重新计算账单。
- 原始英文状态、责任分组与费用代码转换为中文；订单编号保留，便于对应行程。
- 原始 JSON 展开替换为中文规则、计算步骤和逐路口/偏离段说明；金额变化项优先且默认展开。
- 无归因账单显示等待状态；缺失轨迹只显示已知起终点；底图加载失败显示文字提示。
- 地图弹窗使用文本转义，视角切换支持键盘，页面适配手机并尊重减少动态效果设置。
- 复核表单只提供所选订单的费用选项，近期申请展示中文身份与状态。

## 取舍

- 用“待核实差额”替代主界面“残差”，在核对说明中保留两者关系。
- 首页不再展示开发命令；开发者接口文档保留在页脚。
- 地图保留开放街道地图贡献者署名，街道底图仍依赖外部网络。

## 自检

1. 费用是否来自同一份保存的账单证据？是，页面金额直接取归因记录。
2. 是否把绕路费重复计入里程变化？否，展示已有扣除过程。
3. 轨迹缺失是否展示猜测路线？否，仅绘制已知起终点。
4. 乘客和司机看到的总额是否一致？是，仅更换说明角度。

## 验证结果

- 完整 pytest：83 passed，1 条既有依赖弃用提示，耗时 2.90 秒。
- 使用 Edge 的 Playwright 运行真实浏览器检查：1440 像素桌面、390 像素手机下三个页面无页面横向溢出。
- 验证乘客/司机切换、非零费用默认展开、其他费用折叠展开、订单与费用联动、切换订单清除旧费用选择。
- 验证夜间档与长途返空费账单，断开地图组件网络后显示中文降级提示；浏览器无 JavaScript 错误。
